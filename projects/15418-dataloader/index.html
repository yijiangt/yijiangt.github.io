Thread-Based PyTorch DataLoader on Free-Threaded Python

James Tian (jamestia) · Yueqi Ren (yueqir)

Proposal Milestone Report Final Report Poster Code

Summary

We are going to build a thread-based backend for PyTorch’s DataLoader on free-threaded Python 3.14 with work-stealing scheduling, backpressure, and zero-copy collation, and compare it against multiprocess loading on GHC and NCSA Delta in throughput, CPU efficiency, memory, and tail latency.
